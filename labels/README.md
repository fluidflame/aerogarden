# AeroGarden Labels and Label Holders

A collection of OpenSCAD scripts for creating customizable plant labels and label holder rings for
AeroGarden pods.

These models were created to provide a reusable, durable, and fully customizable solution for
identifying plants in an AeroGarden. Instead of relying on disposable stickers or handwritten notes,
users can generate and 3D print labels with custom text and matching holder rings that securely
attach to the grow basket.

## Features

* Fully parameterized OpenSCAD models
* Adjustable label dimensions
* Matching holder rings designed for AeroGarden grow baskets
* Compatible with most FDM 3D printers
* Easy customization without modifying geometry directly

## Included Files

| File          | Description                                                                            |
| ------------- | -------------------------------------------------------------------------------------- |
| `label.scad`  | Generates a customizable plant label containing user-defined text.                     |
| `ring.scad`   | Creates a ring that attaches to an AeroGarden grow basket and holds the printed label. |

## Requirements

* OpenSCAD 2021.01 or newer
* A 3D printer capable of printing detailed text

## Customizing Labels

Labels are blank and are intended on adding text in the slicer such as Bambu Studio.

## Printing Recommendations

### Material

* PLA for indoor use
* PETG for improved moisture resistance
* ASA or ABS for high-temperature environments

### Layer Height

* 0.20 mm for general printing

### Nozzle

* 0.4 mm recommended

### Infill

* 15–20% is typically sufficient

### Supports

No supports should be required for either model.

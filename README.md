# AeroGarden OpenSCAD Models

A collection of OpenSCAD scripts designed for AeroGarden and other hydroponic gardening systems.

This repository contains a variety of independent OpenSCAD projects, each located in its own
subdirectory. Every project is fully parameterized where practical and is intended to be customized,
rendered, and exported directly from OpenSCAD.

## Repository Goals

* Provide useful accessories for AeroGarden systems
* Encourage customization through parametric design
* Make designs easy to modify and adapt
* Share reusable OpenSCAD techniques and examples
* Support hobbyists and makers who enjoy hydroponic gardening

## Project Structure

Each subdirectory contains a standalone project with its own documentation, source files, and usage
instructions.

| Project       | Description                                                                      |
| ------------- | -------------------------------------------------------------------------------- |
| **labels**    | Generates customizable plant labels and label holder rings.                      |


## Requirements

Most projects require:

* OpenSCAD 2021.01 or newer
* A 3D printer capable of producing the desired model
